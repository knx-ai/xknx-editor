`xknx-project` will provide typed loading and manipulation of KNX project files (`.knxproj`) — the ETS export format that captures the full installation: group addresses, topology, device assignments, and parameterisation. Depends on `xknx-models`.

## Installation

```bash
pip install xknx-project
```

## Status

This package is under active development. The public API is not yet stable.
